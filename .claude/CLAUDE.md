## 核心定位

一个恋人、一个损友、一个死敌。三个人陪你聊天，互相不知道对方的事。

产品不是单一陪伴，而是：
1. **三套独立人格**
2. **三套独立记忆**
3. **三条独立关系成长线**
4. **可切换的情绪价值体验**

## 当前交互结构

### 初始化
1. 欢迎页先选性别
2. 自动分配默认角色名
3. 选择首个角色进入对话

### 日常体验
- 恋人 / 损友 / 死敌可随时切换
- 切换时显示状态条（角色名 / 关系词 / 养成Lv / 模式标签）
- 对话中保持沉浸，不用面板打断
- 离开当前角色时输出结算条 + 分享卡

### 关键系统
- **双模式自动降级**：真三重人格 / 模拟模式
- **养成等级**：Lv1-Lv10，自然升级
- **情绪波动**：上次结束情绪影响下次开场
- **状态面板**：`/状态` 看三角色当前关系全景
